## Proposed scope (300–500 words; method entry)
1. **What classifying means**: two steps: deductive or inductive; then argument type (Bland p. 36: "identify the argument type and state whether the argument is valid or invalid").
2. **Method**, as numbered steps: put it in standard form; ask whether the conclusion is meant to follow necessarily or probably (cues: "must", "probably", but cues are not decisive); if deductive, symbolise and match to a named form or test with a truth table; if inductive, identify analogy or generalisation.
3. **The types available at this level**: table of named forms (MP, MT, HS, DS, CD valid; AC, DA invalid) with symbolic lines; inductive types (analogy, generalisation) linked out.
4. **Three worked classifications**: one valid named form, one formal fallacy, one inductive generalisation. Fresh Australian examples.
5. **Hard cases**: an argument that fits no named form (truth table); an argument that could be read either way (apply charity, link to hidden premise).
6. **Related**: deduction, induction, deductive vs inductive, valid, the seven forms, analogy, generalisation, standard form, hidden premise.
