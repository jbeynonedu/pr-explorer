## Proposed scope (350–500 words)
1. **Definition**: a claim is true if things are as it says they are, and false if they are not (correspondence, as the working account). Truth and falsity belong to claims (propositions), never to arguments; link `proposition` for truth value and bivalence rather than restating them.
2. **Theories of truth** (section Q3): correspondence, coherence, pragmatic, one or two neutral sentences each; no verdict.
3. **Truth is not belief, certainty or proof**: a claim can be true though no one believes it, or believed though false; we can be uncertain of a true claim. Inductive support makes a claim probable, it does not make it true (style guide §2).
4. **How claims are checked**: empirical claims by evidence (Bland p. 66, the minimum-wage menu-style check); some claims are true by the meanings of words (e.g. "All bachelors are unmarried"). One line: normative claims and the dispute over whether they are true or false, linking `descriptive-normative`.
5. **Truth and argument quality**: true premises + valid form = sound; a valid argument can have a false conclusion; a true conclusion does not make an argument good. One short example, linking `valid` and `sound` (no truth table needed).
6. **Common mistakes**: "this argument is true/false"; "true for me" used to mean "I believe it"; treating "false" as "unproven".
7. **Related**: proposition, claim, plausible, credible, valid, sound, strong-weak, descriptive-normative.
