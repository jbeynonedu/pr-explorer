## Proposed scope (250–400 words)
1. **Definition** (Bland p. 18; p. 36): valid if and only if the truth of the premises guarantees the truth of the conclusion; equivalently, it is impossible for the premises to be true and the conclusion false. Invalid otherwise.
2. **Form, not content** (Bland p. 18): the moon-made-of-cheese example or a fresh absurd-but-valid one.
3. **The four combinations** table: true premises/true conclusion, false/false, false/true, true/false. Only the last is ruled out by validity. A false conclusion does not make an argument invalid; a true conclusion does not make it valid.
4. **Testing validity**: recognise a named form (link to the five valid forms and two formal fallacies); otherwise a truth table: a row with all true premises and a false conclusion is a **counterexample** (Bland p. 50). One worked invalid example with its counterexample.
5. **All-or-nothing** (Bland p. 19, p. 36): never "partly valid" or "more valid".
6. **Related**: deduction, sound, counterexample (in-entry), logical operators, the five forms, affirming the consequent, denying the antecedent, hidden premise.
