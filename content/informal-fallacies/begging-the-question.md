# Begging the question

*Petitio principii*

**An argument begs the question when its premises assume the truth of the conclusion they are meant to support.** Often the conclusion is slipped in among the premises in slightly different words. The fallacy is also known as *circular reasoning*; that name is sometimes kept for longer versions with more than one inference. It is an [informal fallacy](informal-fallacy) of presumption.

## The pattern

```sf
1. P (stated directly or indirectly).
C. Therefore, P.
```

A longer, circular version:

```sf
1. P.
2. If P, then Q.
IC. Therefore, Q.
3. If Q, then P.
C. Therefore, P.
```

Here P is used to support Q, and Q is then used to support P.

To spot it, ask: if I did not already accept the conclusion, would the premises give me any reason to accept it? If not, the argument probably begs the question.

## Circular but valid

A question-begging argument is usually [deductively valid](valid): it cannot have true premises and a false conclusion. So the problem is not that the conclusion fails to follow.

The problem is that the argument gives no independent reason. In the simplest version it is a disguised repetition. Someone who doubts the conclusion has exactly the same reason to doubt the premise, so the argument cannot move them. Begging the question is a failure to *support* the conclusion, not a failure of logical form.

## Examples

A student says, "Everything on this website is accurate. It says on its home page that everything it publishes is accurate, and it wouldn't say that if it weren't true."

```sf
1. The website says that everything it publishes is accurate.
2. The website would not say that if it were not true.
C. Therefore, everything the website publishes is accurate.
```

Premise 2 is acceptable only to someone who already trusts the website, which is the point in question.

A diner argues, "This is the best pizza place in town, because no other pizza place in town is as good."

```sf
1. No other pizza place in town is as good as this one.
C. Therefore, this is the best pizza place in town.
```

The premise and conclusion make essentially the same claim. No reason has been given.

Loaded wording can also beg the question. Calling a disputed rule "unfair censorship" in a premise assumes the very point that is in dispute: whether the rule is unfair.

## When it is not fallacious

In every valid argument, the premises cannot be true while the conclusion is false. That alone is not begging the question. The argument begs the question only when a key premise is acceptable *only* to someone who already accepts the conclusion. If the premises can be defended independently of the conclusion, there is no fallacy. See also [limitations of deduction](limits-of-deduction).

## A common mistake

In everyday speech, "this begs the question" is often used to mean "this raises the question". For example: "The rise in costs begs the question of who will pay." That everyday use is not this fallacy. In logic, "begging the question" means assuming the conclusion.
