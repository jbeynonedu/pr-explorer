# Slippery slope

**A slippery slope argument claims that a first, modest step will lead through a chain of consequences to an extreme and undesirable outcome, so the first step should not be taken. It is a fallacy when the links in the chain are not supported, or their likelihood is exaggerated.** It is an [informal fallacy](informal-fallacy). The key word is often "inevitably": the argument assumes momentum that has not been shown.

## The pattern

```sf
1. If A happens, then B will happen.
2. If B happens, then C will happen.
3. If C happens, then D will happen.
4. D is unacceptable.
C. Therefore, A should not happen.
```

Set out like this, the argument looks like a [hypothetical syllogism](hypothetical-syllogism) followed by [modus tollens](modus-tollens), and those forms are valid. The problem is not the form but the premises. In real slippery slopes, each "if... then" is at best probable, so the argument has to be judged as an inductive chain.

## Why long chains are weak

Small uncertainties add up. Suppose each step, once reached, has an 80 per cent chance of leading to the next. Then the chance of going all the way from A to E over four such steps is 0.8 × 0.8 × 0.8 × 0.8, which is about 0.41. The end of the chain is less likely than not, even though every single step looked likely.

## Examples

A student is told, "If you hand in this one assignment late, you'll start missing other deadlines, then you'll fail the subject, then you won't finish school."

```sf
1. If you hand in this assignment late, you will miss other deadlines.
2. If you miss other deadlines, you will fail the subject.
3. If you fail the subject, you will not finish school.
4. Not finishing school is unacceptable.
C. Therefore, you must not hand in this assignment late.
```

Handing in work on time is a good idea, but premises 1 and 2 are not supported. One late assignment does not make the later steps likely.

A council debate about allowing food trucks in a park on weekends: "First it's weekends, then every day, then the park becomes a car park for trucks, and the families stop coming." Each step may be possible, but no reason is given that the first leads to the second, or the second to the third.

## When it is not fallacious

Not every argument about a chain of consequences is a fallacy. If each link is well supported by evidence, the argument may be inductively [strong](strong-weak). Whether it is depends on the probability at each step.

Some slippery slopes depend on vague terms rather than causes. If removing one hair never turns a bearded man into a beardless one, it can seem that removing hairs one by one never could. Puzzles like this raise genuine questions about vague words, not just a mistake about consequences.
