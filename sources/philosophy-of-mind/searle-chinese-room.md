Content notes (paraphrase, from the full text):
- Strong vs weak AI distinction; target is strong AI; example is Schank & Abelson (1977) story-understanding programs (Yale).
- Room: Searle knows no Chinese; receives batches of Chinese writing ("script", "story", "questions") and English rules ("the program"); returns symbols ("answers") indistinguishable from native speakers'; contrast with English case where he understands.
- Two claims attacked: (1) the computer understands; (2) the program explains human understanding. Program gives neither sufficient conditions, nor reason to think necessary conditions.
- Systems reply: the whole system understands. Reply: internalise the system (memorise rules, work outdoors); still no understanding; also: reply begs the question; would make stomach etc. "understanding subsystems".
- Robot reply: computer in a robot with camera and motors. Reply: concedes cognition is not only symbol manipulation; put Searle inside the robot; symbols from camera; still no understanding.
- Brain simulator reply: simulate neuron firings of a Chinese speaker. Reply: water-pipes version; simulates formal structure, not causal powers.
- Other minds reply: we know others understand only by behaviour. (Searle's answer: the question is not how I know others have cognitive states but what I attribute when I attribute them.) *Check exact wording before use.*
- Positive view: brains cause minds; machine could think if it had causal powers equivalent to brains; "only a machine could think" (abstract).

## sep-chinese-room (checking; no quotation in entry)
Cole, D., "The Chinese Room Argument", *Stanford Encyclopedia of Philosophy*, first published 19 Mar 2004; substantive revision 23 Oct 2024. https://plato.stanford.edu/entries/chinese-room/ (Chrome, 25 Nov 2026).
- Searle's dates: "American philosopher John Searle (1932–2025)" (live page; archived versions to spring 2026 give "1932– ").
- Narrow argument as reductio (§3): If Strong AI is true, there is a program for Chinese C such that any system running C understands Chinese; I could run C without understanding Chinese; therefore Strong AI is false.
- Replies grouped by concession (§4): (1) concede man doesn't understand, but something else might (systems, virtual mind); (2) concede the room doesn't understand but a variant could (robot, brain simulator); (3) concede nothing (intuition, other minds).
- Systems reply endorsed by Block, Copeland, Dennett, Hofstadter, Fodor, Haugeland, Kurzweil, Rey (§4.1). Virtual mind reply: Minsky, Sloman and Croucher, Maudlin, Cole, Chalmers (§4.1.1).
- Robot reply: Boden, Crane, Dennett, Fodor, Harnad, Moravec, Rey (§4.2); appeals to causal connection with the world.
- Intuition reply (§4.5): Dennett called it an "intuition pump"; Block: intuitions can be overridden.
- §4.6 Advances in AI: LLMs trained on web-scale text, unlike Schank's hand-built program; asks whether this makes any difference to the argument; reports views that LLMs understand in some sense (e.g. Hossenfelder 2023, Huang 2024); author leans against Searle here.
- Turing (1950) proposed the Turing Test (§1, §2.2).
